# Contributing

Thanks for helping improve AI GitHub Blogger.

## Getting started

1. Fork the repository and create a focused branch from main.
2. Install dependencies:

    pip install -r requirements.txt

3. Run the test suite:

    pytest tests/ -v

## Pull requests

Keep changes focused and explain what changed and why. Before opening a pull request, run the relevant tests and update documentation when user-facing behavior changes. Do not include API keys, tokens, generated content packages, or unrelated formatting changes.

## Issues and proposals

Use the issue templates for bug reports and feature proposals. For substantial changes, open an issue first so the approach can be discussed before implementation.
